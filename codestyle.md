# Code Style

## JavaScript

- Use `camelCase` for variables and functions.
- Use `const` by default.
- Use `let` only when reassignment is necessary.
- Use `async/await` for asynchronous operations.
- Avoid unnecessary global variables.
- Keep functions focused on a single responsibility.

## HTML

- Use clear and meaningful element structure.
- Use meaningful class and id names.
- Keep the page structure simple and readable.

## CSS

- Group related styles together.
- Use consistent indentation.
- Prefer reusable class selectors.
- Use responsive design for different screen sizes.
- Keep colors, spacing, and typography consistent.

## Error Handling

- Catch failed API requests.
- Display understandable error messages to users.
- Do not perform the actual calculator logic in the frontend.
- Send expressions to the backend for calculation.
