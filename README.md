# Web Calculator Frontend

Software Engineering Practice - Assignment 1

## Project Description

This project is the frontend of a web calculator.

The frontend communicates with the FastAPI backend through REST APIs.

## Features

- Button-based calculator interface
- Keyboard expression input
- Four arithmetic operations
- Parentheses and decimal numbers
- Error message display
- Calculation history
- Reuse history expressions
- Delete history records
- Responsive web interface

## Technology Stack

- HTML
- CSS
- JavaScript
- Vite
